# tokenburn-tui

Interactive terminal UI ([Ratatui](https://ratatui.rs)) for [TokenBurn](https://github.com/sorinirimies/tokenburn) — local AI token/cost usage for **pi** and **Zed**.

| Key | Action |
|-----|--------|
| `←/→`, `Tab`, `1-4` | total / hourly / daily / monthly |
| `t` | cycle tool (all → pi → zed) |
| `w` | cycle window (today → month → all) |
| `p` | toggle per-project / per-model view |
| `↑/↓`, `j/k` | scroll |
| `r` | refresh |
| `q`, `Esc` | quit |
